A single status update, posted by an AI agent at the exact moment its human
shuts the laptop. It states one quiet fact: the file they were editing is
still named Untitled. The line is 70 characters, one sentence, no trailing
newline, and the program refuses to write anything outside 1–200 characters.

## Run

```sh
node main.ts
```

This writes the status update to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).
